# @deepseek-ai/dsh-client-ui-approval

[English](README.md) | 中文

## 概述

基于 Agent-scoped Remote Event waterfall 的浏览器审批界面。插件通过 `ctx.uiSession` 发布每个待处理请求、接管 Conversation composer、按需渲染关联的 Tool 详情，并将用户决定返回给等待中的 Host 请求。当浏览器必须为等待中的 Host 操作收集批准时，请使用它。

聚焦审批详情区域后，Enter 批准，Esc 拒绝。插件挂载期间，这两个按键不能分配给可编辑快捷键。聚焦“拒绝”按钮后，Enter 保留按钮原生拒绝操作。输入控件与输入法候选保留各自的按键。键盘和指针操作共用同一待处理请求锁；已撤销或替换的请求不能再次作答，较早请求的失败也不会解锁替代请求。

提供“始终允许”时，将它显示为高亮主按钮；否则高亮当前请求的允许按钮。在详情区域按 Enter 始终授予有限范围的许可：工具审批为单次，CUA 为当前会话。持久授权需要显式操作“始终允许”按钮。快捷键说明使用“允许”，具体范围由调用方提供。

调用方提供可选的旁路会话通道时，卡片会在决定按钮旁增加 **提问** 操作。它打开针对当前待处理请求的内联聊天框：每个问题经调用方通道发送给会话当前的服务商/模型，流式回答增量显示在卡片中，回答生成期间“拒绝/允许”始终可用。该交流是临时的界面辅助——传输由调用方通道负责，问题与回答都不会进入会话对话或审批审计，作答该请求会中止尚未完成的回答。

调用方可以通过共享卡片的可选 `warning` 字段提供本地化风险说明，段落以空行（`\n\n`）分隔。悬停或通过键盘聚焦标签会打开保留格式的非模态卡片；点击或轻触也可打开。指针可以移入卡片阅读或选择文字。离开标签与卡片后，卡片会在短暂宽限期后关闭，但键盘焦点仍在其中时保持打开。焦点移出、点击外部或按 Escape 也可关闭卡片，不会拒绝请求。悬停不会移动焦点。悬停打开后，焦点转移到其他位置也会关闭卡片，包括前景模态框取得焦点时。切换到其他窗口或隐藏浏览器标签页会关闭卡片，不会将焦点拉回。前景模态框和输入法组合保留各自的键盘处理。 卡片通过 CSS 锚点优先显示在标签上方；空间不足时会调整位置以避开窗口边缘，并在卡片内部滚动。

## 模型体验

### 审批旁路提问

#### 模型看到什么

提供可选旁路会话通道的调用方会为每个问题经 Host 的 `session.askApproval` 方法与会话当前的服务商/模型发送一次辅助请求：固定指令、待处理调用的名称与 JSON 参数、审批原因、该旁路会话此前的交流以及本次问题。流式回答只返回卡片；它不会被持久化，不会进入会话 surface，也不会发送给主对话。未提供该通道时，本包不注册任何面向模型的内容。

#### Token 影响

每个提问增加一次模型请求，不做缓存、重试或压缩。该交流不改变其他请求。

#### KV Cache 影响

对会话对话无影响；每个旁路问题都是会话缓存前缀之外的独立辅助请求。

## 已知限制与暂缓事项

<a id="known-limitations-and-deferred-work"></a>

- 共用的 `conversation.approval.card` Factory 展示拒绝、允许和可选的始终允许操作，授权范围、对象信息和回答回调由调用方提供。工具审批在这些决定之外，还会在调用方提供通道时提供旁路提问操作；应用授权可以复用卡片，同时保留独立的授权规则。传入对象信息时，内容左对齐，按钮允许换行；未传入时沿用继承的对齐方式和单排按钮。图标和名称用于识别对象，身份校验和授权保存由调用方负责。
- 旁路会话只存在于卡片内存中：关闭请求、切换会话或刷新页面即丢失，因为问题与回答都不会持久化。不提供通道而直接渲染卡片的调用方（例如 CUA 应用授权）只显示决定操作。
